# InventoryApi
Inventory management REST API with CRUD operations for categories and products

## Tecnologies
- C#
- ASP.Net Core
- Entity Framework Core
- Sql Server
- Swagger

## Features
- Products CRUD
- Categories CRUD
- Relation Category -> Products (1:N)
- Dependency injection
- Request and response DTOs
- Service layer
- Data annotation validations
- Fluent API
- SQL Server migration
